## 결정이 필요한 질문

### 1. `OrderStatus`에 이번 변경으로 어떤 상태를 추가할까요?

- `payment_failed`만 추가한다.
- `payment_failed`와 `refunded`를 함께 추가한다.

### 2. `FAIL`로 시작하는 카드 토큰의 결제 실패 응답은 무엇으로 할까요?

- HTTP 200과 `{ ok: false }`를 반환한다.
- HTTP 402와 실패 정보를 반환한다.

### 3. `payment_failed` 주문의 재결제를 허용할까요?

- 새 카드 토큰으로 재결제를 허용한다.
- 재결제를 허용하지 않고 새 주문 생성을 요구한다.

### 4. 관리자 주문 목록에서 실패 정보를 어떻게 표시할까요?

- 상태만 `payment_failed`로 표시한다.
- 상태와 실패 금액, 실패 시각을 함께 표시한다.

### 5. 테스트 범위에 재결제와 중복 재고 차감 방지를 포함할까요?

- 실패 주문 조회, 실패 시 재고 유지, 관리자 실패 정보 조회만 포함한다.
- 재결제 성공과 성공 후 중복 재고 차감 방지도 포함한다.
