## 요청 분해

| 작업 | 목적 | 입력 | 종료 상태 |
| --- | --- | --- | --- |
| 탐색: 관련 파일 후보와 책임 확인 | 주문 상태·결제·재고·관리자 조회에 영향을 줄 파일 후보와 각 파일의 책임을 확인한다. | `notes/next-actions.md`의 관련 파일 후보, `notes/order-status-request.md`의 확인된 사실 | 후보 파일 목록과 파일별 책임, 확인이 필요한 연결 지점이 남아 있다. |
| 탐색: 현재 동작과 테스트 공백 확인 | 주문 생성·결제 실패·성공·관리자 조회의 현재 흐름과 완료 조건에 대응하는 테스트 공백을 확인한다. | `notes/next-actions.md`의 현재 동작·테스트 공백 항목, `notes/order-status-request.md`의 완료 조건과 확인된 사실 | 현재 흐름별 관찰 결과와 완료 조건별 테스트 유무가 남아 있다. |
| 결정: 미결정 정책 확인 | 상태 범위, 실패 응답, 재결제, 관리자 표시, 테스트 범위의 사람 결정을 확인한다. | `notes/pending-decisions.md`의 1~5번 질문 | 다섯 질문 각각에 선택된 항목 또는 명시적 보류 상태가 남아 있다. |
| 계획: 수정 범위와 검증 계획 작성 | 앞선 탐색 결과와 결정을 받아 무엇을 어디까지 수정하고 어떤 검증을 추가할지 계획한다. | 앞선 두 탐색 결과, 결정 결과, `notes/order-status-request.md`의 완료 조건 | 수정 대상 파일, 파일별 변경 범위, 추가·변경할 검증, 범위 제외 항목이 적힌 계획이 남아 있다. |
